# GAUGE: How Large Language Models Recover Mobility Descriptors from Individual Records

Mustafa Sameen, University of Florida. UMFM @ ACM SIGSPATIAL 2026.

- Project page: https://mustafasameen.github.io/GAUGE/
- Paper (PDF): https://mustafasameen.github.io/GAUGE/static/GAUGE_UMFM26.pdf

GAUGE asks language models to recover mobility descriptors, such as radius of gyration, from one person's
location record. The code that rebuilds the benchmark questions from YJMob100K and scores model answers will be
added to this repository. The project page lives in `docs/`.
